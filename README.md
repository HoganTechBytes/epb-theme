# Electric Purple Black (EPB)

Electric Purple Black (EPB) is a dark VS Code theme built around one simple goal:

**Pure black background + electric purple vibe + clean readability.**

This theme was made for everyday work (especially SQL), but it’s designed to stay usable across multiple languages.

---

## Theme Goals

- **True black background** (`#000000`)
- **Electric purple primary color** (`#AA00FF`)
- Readable syntax highlighting without overwhelming contrast
- Comfortable for long coding sessions
- Works well across:
  - SQL / MySQL
  - JSON
  - Python
  - Bash
  - Java / C / C++

---

## Color Palette (Core)

- Background: `#000000`
- Foreground / identifiers: `#B58DFF`
- Keywords: `#AA00FF`
- Types / classes: `#C566FF`
- Functions / methods: `#3A66CC`
- Strings: `#5FB3C2`
- Numbers / constants: `#5CFFB3`
- Comments: `#6F4A99`

---

## Install (Local VSIX)

This extension is currently intended for local use (not published to the Marketplace).

### Install using VS Code

1. Open VS Code
2. Go to **Extensions**
3. Click the `...` menu (top-right)
4. Choose **Install from VSIX...**
5. Select the `.vsix` file (example: `electric-purple-black-0.0.5.vsix`)
6. Reload VS Code if prompted

### Install using the command line

From the folder containing your `.vsix` file:

```bash
code --install-extension electric-purple-black-0.0.5.vsix
